Changes:
  1. Added: StorageService integration
  2. Enhanced deleteMessage() to use StorageService
  3. Removed: Unused ChatAttachmentHandler import

New Flow for deleteMessage():
  ┌─────────────────────────────────────┐
  │ deleteMessage(messageId, forEveryone)│
  └──────────┬──────────────────────────┘
             │
      ┌──────▼──────┐
      │ ensureAuth()?│
      └──────┬──────┘
             │
      ┌──────▼──────────────────────────┐
      │ Get message data + attachment_url│
      └──────┬──────────────────────────┘
             │
      ┌──────▼──────────────────┐
      │ forEveryone = true?     │
      └──────┬────────────┬─────┘
             │ YES        │ NO
         ┌───▼────┐   ┌───▼──────────────────┐
         │Delete  │   │Create hidden_messages│
         │file    │   │ (for current user)   │
         │from    │   └───┬──────────────────┘
         │cloud   │       │
         └───┬────┘   ┌───▼──────────────────┐
             │        │Don't delete file     │
         ┌───▼────┐   │(other user may view) │
         │Delete  │   └─────────────────────┘
         │message │
         │from DB │
         └───┬────┘
             │
         ┌───▼──────────────┐
         │Delete from local │
         │(Sembast)         │
         └───┬──────────────┘
             │
         ┌───▼─────────────┐
         │Return Result    │
         └─────────────────┘

Logic Changes:
  - forEveryone = true  → Delete file from cloud + Delete message from DB
  - forEveryone = false → Create hidden_messages record (soft delete)

Cost Saving:
  • Before: Orphaned files in cloud storage (wasted space)
  • After:  Files deleted immediately when message deleted for everyone

      context,

        // Open image picker
        final result = await ImagePicker().pickImage(...);
        if (result != null) {
          // Send to repository
          final chatActions = ref.read(chatActionsProvider.notifier);
          await chatActions.sendMessage(
            SendMessageParams(
              conversationId: conversationId,
              content: '',
              attachmentUrl: fileUrl,
              attachmentType: 'image',
            ),
          );
        }
      },
      onCameraTap: () async {
        // Take photo with camera
      },
      onFileTap: () async {
        // Pick file
      },
    );
  }

⚠️ IMPORTANT NOTES

1. Database Schema
   Ensure hidden_messages table exists:
   ```sql
   CREATE TABLE hidden_messages (
     message_id TEXT NOT NULL,
     user_id TEXT NOT NULL,
     hidden_at TIMESTAMP DEFAULT NOW(),
     PRIMARY KEY (message_id, user_id)
   );
   ```

2. Supabase Storage Policy
   Bucket: chat_attachments (must exist)
   - Allow: authenticated users to upload
   - Allow: users to delete own files
   - Public: false (security)

3. URL Format
   StorageService expects standard Supabase URLs:
   https://{project}.supabase.co/storage/v1/object/public/{bucket}/{path}

4. Error Handling
   - File deletion failures are logged but don't crash app
   - Message deletion continues even if file deletion fails
   - Check logs for orphaned files: "Error deleting file from cloud"
